Systèmes

Active Directory & DNS

Un domaine Windows avec utilisateurs, groupes et poste client intégré, selon le modèle AGDLP.

Objectif

Centraliser la gestion des comptes et des droits d'accès, et connecter un poste client au domaine.

Ce que j'ai réalisé

  • Installation d'Active Directory Domain Services et du DNS sur Windows Server.
  • Création des unités d'organisation, des utilisateurs et des groupes.
  • Application du modèle AGDLP pour attribuer les droits par groupes.
  • Jonction d'un poste client au domaine et vérification de l'ouverture de session.

Technologies

  • Windows Server
  • AD DS
  • DNS
  • AGDLP
