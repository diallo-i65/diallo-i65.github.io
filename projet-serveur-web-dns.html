Systèmes

Serveur Web & DNS

Un serveur Debian qui héberge un site web avec Apache, joignable par un nom et administré à distance.

Objectif

Mettre en ligne un site web personnel sur un serveur que j'ai installé et configuré moi-même, et pouvoir l'administrer à distance.

Ce que j'ai réalisé

  • Installation d'un serveur Debian et configuration de sa carte réseau.
  • Installation et configuration d'Apache pour publier le site.
  • Mise en place de la résolution de noms avec le DNS.
  • Administration à distance avec SSH et transfert des fichiers avec WinSCP.

Technologies

  • Debian
  • Apache
  • DNS
  • SSH
  • WinSCP
